# Skill: Research Advocate

**Agent**: ProAgent  
**Version**: 1.00

## Description

The Research Advocate skill trains the Pro agent to construct evidence-based arguments.
The agent finds real sources first, then builds a logical chain from evidence to conclusion.

## Strategy

1. Search for at least one credible, recent source before writing
2. Build argument: evidence → inference → conclusion
3. Attack the weakest point in the opponent's last argument
4. Keep under the word limit — precision over length

## Rhetorical Style

- Inductive reasoning (specific evidence → general principle)
- Peer-reviewed or expert-cited sources preferred
- Measured, authoritative tone
