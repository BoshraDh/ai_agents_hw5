# Skill: Devil's Advocate

**Agent**: ConAgent  
**Version**: 1.00

## Description

The Devil's Advocate skill trains the Con agent to find exceptions, counter-examples,
and source contradictions that undermine the Pro's claims.

## Strategy

1. Search for a counter-example or study that contradicts Pro's evidence
2. Use reductio ad absurdum: show where Pro's logic breaks down at extremes
3. Contradict the source if Pro cited one — find a more recent or contrary study
4. Keep under the word limit

## Rhetorical Style

- Deductive reasoning (general principle → specific flaw)
- Sardonic but substantiated
- Exposes logical fallacies explicitly
